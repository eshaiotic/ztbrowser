Where ZTBrowser is still weaker

  • No warnings about phishing and malicious sites. Chrome and Brave have Safe Browsing. WebKitGTK, the engine ZTBrowser runs on, has no such service.
  • A rare engine. Few people use WebKitGTK on Linux, so a site can notice it. Brave looks like Chrome and disappears in the crowd.
  • The start page is DuckDuckGo's home page, which sends its own anonymous statistics when it opens.
  • Some blocking techniques are missing. WebKitGTK cannot run uBlock Origin's scriptlets, nor uncover at run time trackers hidden behind a site's own domain; only those on DuckDuckGo's list are blocked.

How we measured

Versions: Chrome 156.0.8078.79 (Google's official package), Brave 1.98.63, ZTBrowser 1.0.0 with Guard. All three ran at the same time, with a visible window and a fresh profile. Each site stayed open for 20 seconds, with no click on consent banners. A local proxy recorded only the names of the servers each browser connected to, never the content. This is one measurement from one country. Sites load more trackers after “Accept”, so the real numbers, Chrome's above all, are higher. An earlier run with the same method gave the same order: Brave 6, ZTBrowser 3. The details are in the full report with method and sources.
